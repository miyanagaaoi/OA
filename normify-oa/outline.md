## oa

- oa — 集团OA审批系统 / Group OA Approval System — 面向集团-公司-部门-科室四级组织的企业审批系统：组织与数据域权限（RBAC）、流程定义与运行时引擎、四类审批单据（事项/资金/合同/印鉴证照）、签名附件抄送消… — [模块 526 · API 880]
  - oa.admin — 管理后台 / Admin Console — 组织与人员维护（Excel 批量导入导出）、流程与表单模板配置（走版本发布）、权限树与数据域勾选、数据字典维护、报表统计，以及系统管理员兜底权限的边界约束。 — [模块 66 · API 129]
    - oa.admin.authz — 权限配置 / Permission Admin — 为角色勾选权限树节点与数据域；任何变更写入权限变更日志；仅 IT 部门可分配，分公司流程管理员不可再向下分配。 — [模块 9 · API 15]
      - oa.admin.authz.changelog — 权限变更留痕 / Permission Change Log — 记录角色、数据域、权限树勾选的全部变更（操作人、时间、变更前后值），并提供审计查询与 CSV 导出。 — [模块 1 · API 3]
      - oa.admin.authz.scope — 数据域配置 / Data Scope Admin — 配置每个角色的数据域（本人/本部门/本公司/全集团/全集团按归口类别），为按类别取数的角色绑定事项类别，并试算可见范围。 — [模块 4 · API 6]
        - oa.admin.authz.scope.assign — 角色数据域设置 / Role Data Scope — 在五种允许值中设置角色的 data_scope，并保持角色的集团级/公司级属性与之一致。 — [模块 1 · API 2]
        - oa.admin.authz.scope.category — 归口类别绑定 / Category Binding — 为按归口类别取数的角色绑定可见事项类别，类别选项取自共享字典以保证与表单编码一致。 — [模块 1 · API 2]
        - oa.admin.authz.scope.preview — 可见范围试算 / Visibility Preview — 在数据域配置生效前，通过抽样试算该角色可见的单据范围并展示角色×数据域对照表，便于管理员验收。 — [模块 1 · API 2]
      - oa.admin.authz.tree — 权限树勾选 / Permission Tree Ticking — 为角色勾选权限树节点、设置数据域与归口类别绑定、试算可见范围，并将每次变更留痕；IT 部门逐级分配，分公司流程管理员不可再向下分配。 — [模块 3 · API 6]
        - oa.admin.authz.tree.assign — 角色勾选权限 / Role Permission Ticking — 读写某角色被勾选的权限树节点集合，支持逐级联动与批量勾选，并把勾选差异交给权限变更日志。 — [模块 1 · API 3]
        - oa.admin.authz.tree.delegate — 逐级分配与再分配限制 / Delegation Limits — 控制谁可以向谁分配权限：分公司流程管理员只获得本公司范围内的分配权，并被明确禁止再向下分配。 — [模块 1 · API 3]
    - oa.admin.boundary — 管理员权限边界 / Admin Boundaries — 系统管理员可配置一切，但不可删除已产生的审批单据与审计日志，不可修改已审批通过单据的审批结果；其所有操作均留痕。 — [模块 9 · API 17]
      - oa.admin.boundary.fallback — 兜底权限与改派 / Super-Admin Fallback — 定义系统管理员的兜底能力集，预校验某操作是否落入禁区，并提供快照审批人无法处理时的兜底改派能力（必须留痕）。 — [模块 1 · API 3]
      - oa.admin.boundary.guard — 不可删改硬闸门 / Immutable Guard Gates — 不可删改硬闸门：阻止系统管理员删除已产生的审批单据与审计日志、阻止修改已审批通过单据的审批结果，被拒动作均留痕。 — [模块 3 · API 6]
        - oa.admin.boundary.guard.doc — 单据与日志删除禁令 / Deletion Ban Gate — 硬闸门：拒绝删除已产生的审批单据与审计日志；拒绝动作本身也写入审计日志，不允许静默失败。 — [模块 1 · API 3]
        - oa.admin.boundary.guard.verdict — 已批单据结果冻结 / Verdict Freeze — 冻结已审批通过单据的审批结果（不可改判）；同时保留在途流程的终止（须填原因）与任务改派能力，两者均留痕。 — [模块 1 · API 3]
      - oa.admin.boundary.settings — 系统参数与保留期 / System Settings & Retention — 系统管理员可调的系统级参数：会话与登录策略、审计与日志保留期；参数均带不可越过的硬下限（审计与轨迹保留不得短于 10 年）。 — [模块 3 · API 6]
        - oa.admin.boundary.settings.retention — 审计保留期 / Audit Retention — 可配置项：审计日志与审批轨迹保留期（不得短于 10 年）、登录日志保留期（1 年）；配置值低于下限时拒绝保存。 — [模块 1 · API 3]
        - oa.admin.boundary.settings.session — 会话与登录策略 / Session & Login Policy — 可配置项：同时在线设备上限（默认 3 台，超出踢出最早登录设备）、「记住我」有效期（默认 7 天，期间自动续期）、登录失败锁定（默认 5 次，锁定 15 分钟）… — [模块 1 · API 3]
      - oa.admin.boundary.trace — 管理员操作留痕 / Admin Action Trail — 把管理员的每一次操作（操作人、时间、IP、对象、变更前后值）写入只追加的审计日志，并提供审计查询与 CSV 导出。 — [模块 1 · API 2]
    - oa.admin.dict — 数据字典管理 / Dictionary Admin — 维护事项类别、合同类型、用印类型、证照类型等基础选项；新增选项无需发版即可生效，已被单据引用的选项只能停用不可删除。 — [模块 8 · API 18]

        - oa.admin.dict.delivery.spreadsheet — 字典导入导出 / Dictionary Spreadsheet — 以 Excel 导入导出全量字典，按 dict_type + item_code 幂等，重复导入不会产生重复选项。 — [模块 1 · API 4]
      - oa.admin.dict.item — 字典项维护 / Dictionary Items — 字典项增删改、排序与启停，以及导入导出；已被引用的选项不可删除，新增选项无需发版即可生效。 — [模块 3 · API 8]

      - oa.admin.dict.type — 字典类型管理 / Dictionary Types — 维护字典类型目录（category/pay_method/contract_type/seal_type/cert_name 等），并提供恢复内置默认选项的能力… — [模块 1 · API 3]
